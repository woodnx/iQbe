# 押し位置の集計対象を日別初回解答で識別する

2026-11-16の追加要件Q18〜Q20により、将来の直近・平均の押した位置は、ユーザー・問題・JST日付ごとの最初の保存済み解答が正解だった場合の有効な位置だけを使う。自由演習・今日の5問・スマート復習を共通に数え、中断、再開、別端末、モード切替で初回に戻さない。不正解の後に答えを見て解き直した押し位置を、最初から思い出せた場合と混ぜず、翌日の初回での改善を測れるようにするためである。

各演習回の最初を基準にする案は採用しない。同じ日に回を作り直すだけで集計対象に戻ってしまうためである。初回正解後の同日2回目以降も対象外になる一方、解き直しを含む全解答は履歴・FSRS・従来定義の成長イベントに残す。初回の識別はサーバーの保存順で確定し、同時送信や再送で増やさない。生涯の初正解イベントを日別初回の代用にしない。

今回の範囲は識別情報と元の押し位置を保存する要件までであり、表示API・画面は後続。過去のモード・復習回は不明として扱い、日別順序は保存済みの日時・履歴IDから再現できる範囲で判定する。
