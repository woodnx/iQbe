# 当日の完了と長期的な学習状態を分離する

2026-11-16の要件確認で、日替わりセットへの正解による当日の完了と、すべての実際の解答を反映する長期的な学習状態を別に持つと決めた。複数端末から同じ項目を解答した場合も両方の履歴・FSRS更新を受け入れ、一度成立した当日の完了は後から届いた不正解で取り消さない。日々の達成を巻き戻さず、記憶状態の推定には不正解という情報を残すためである。

自由演習の正解で日替わりの項目を自動完了させる案、完了済み項目への別端末の解答を拒否する案は採用しない。自由演習で長期の復習期限が延びても日替わりの解き直しを何日も待たせないよう、日替わりの再出題予定も区別する。保存・API・集計の設計では、当日の完了数、解答回数、定着推定を互いの代用にしない。
